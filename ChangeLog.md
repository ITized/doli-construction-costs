# ChangeLog

## 1.0.0 - 2026-03-12

### Added
- Initial module structure following Dolibarr module builder template
- Configurable pricing rules with base multiplier and Main d'Oeuvre (MO) hourly rate
- Margin management (percentage-based) for products and services
- Supplier configuration framework for external price sources
- CSV import support for construction products and services
- Multi-supplier support with EAN/barcode-based product matching
- Construction-specific product categories (Gros Oeuvre, Second Oeuvre, etc.)
- Admin setup page with comprehensive configuration options
- French and English language support
- PHPUnit test infrastructure
- GitHub Actions CI/CD pipeline
- Sample CSV data files for construction sector products and services
